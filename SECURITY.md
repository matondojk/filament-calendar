# Security Policy

## Supported Versions

Currently, we only provide security updates and patches for the latest major version of this package. We encourage all users to stay up-to-date with the latest releases to ensure the highest level of security.

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of this project very seriously. **Please do NOT report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability within this project, please report it privately using GitHub's built-in private vulnerability reporting tool:

1. Go to the **Security** tab of this repository.
2. Click on **Report a vulnerability** (or "Advisories" > "Report a vulnerability").
3. Fill out the form with the details of the vulnerability, including steps to reproduce it if possible.

All security vulnerabilities will be promptly addressed. You should receive a response from the maintainers acknowledging the receipt of your report, and we will keep you informed on the progress of the fix.

Thank you for helping keep this project safe!
